[Next.js](https://nextjs.org) es un framework de React para construir aplicaciones web. En este tutorial creamos un proyecto desde cero.

## Crear el proyecto

Ejecuta el siguiente comando en tu terminal:

```bash
yarn create next-app mi-proyecto
cd mi-proyecto
yarn dev
```

### Tu primera página

Crea el archivo `src/pages/hola.js`:

```jsx
export default function Hola() {
  return <h1>¡Hola desde el Caribe!</h1>
}
```

## Lo que aprendimos

1. Crear un proyecto con `create-next-app`.
2. Levantar el servidor de desarrollo.
3. Crear una página nueva.

| Comando     | Descripción                 |
| ----------- | --------------------------- |
| `yarn dev`  | Servidor de desarrollo      |
| `yarn build`| Build de producción         |
